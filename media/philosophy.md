# Registered Light

*A visual philosophy for BETA ART's share image and icons. It was written with the canvas-design skill, and every media asset in the release package follows it.*

Registered Light treats an image as an entry in a catalogue first, and a picture second. The surface is uncoated paper: warm white with no gradient and no texture laid over it. Structure comes from hairlines, the thin rules a registrar draws before anything is written. A registration cross fixes one point on the field, and everything else is measured from that point. Negative space is a large, deliberate reserve. It is the page waiting for evidence that has not arrived, and the page does not pretend otherwise.

There is one colour event, and it is small: a single oxide-red point where the aperture's blades meet. Ink is black. The rules are the grey of a pencilled margin. Nothing else is coloured. Because the red occurs only once, it reads as a seal, not as decoration, and the eye returns to it every time. Every value in the palette was chosen so the red never has to compete.

The aperture works as a lens and as a stamp. Six straight blades inside a perfect circle, drawn at one even stroke weight, with no shading and no glow. Scale is the only thing that changes. It is monumental on the share card and reduced to its essential circle and point in the browser tab. Each size is redrawn with care, so the mark still reads at sixteen pixels as clearly as it does at six hundred.

Type is sparse and set precisely. A high-contrast serif carries the name, set tightly, as if cut into the plate. A monospaced face appears only where a record would carry it: index lines, identifiers and scale marks, small and evenly spaced. Text never explains the picture. It labels it, as a museum label names an object without describing it.

Rhythm comes from patient repetition. A ruler of fine ticks runs along the lower edge like the edge code of a film strip, and every tenth tick is longer. It measures nothing that is shown, and it tells the viewer the field is under observation. Margins are generous and alignments exact. Nothing touches an edge it has not been assigned to. The finished surface should look as if a conservator spent days placing a handful of lines, and then removed one more.
